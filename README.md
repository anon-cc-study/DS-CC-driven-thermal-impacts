# DS-CC-driven-thermal-impacts
# Load Forecasting, Thermal Modeling, and Power Flow Analysis Pipeline

This repository contains the complete computational workflow used to preprocess weather and load data, train machine learning load forecasting models, generate scenario-based predictions, construct weather-dependent thermal model inputs, perform power flow analyses, post-process model outputs, and generate the main result figures and grid-reinforcement cost estimates reported in the manuscript.

The code is provided to support transparency and reproducibility of the analyses presented in the manuscript **"Compounding climate thermal risks in power distribution networks"**.

## 1. System Requirements

### Hardware Requirements
The code requires a standard computer with enough RAM to support in-memory operations.
* **RAM:** 16 GB+ recommended (dependent on dataset size).
* **CPU:** 4+ cores recommended for parallel processing.
* **GPU:** Not required.

Running the full analysis pipeline across all distribution networks and weather years studied in the paper is computationally intensive and is best executed on a high-performance computing (HPC) system to reduce runtime and accommodate memory and storage demands.

## 2. Installation Guide

### Instructions
1.  Clone the repository:
    ```bash
    git clone https://github.com/anon-cc-study/DS-CC-driven-thermal-impacts.git
    cd DS-CC-driven-thermal-impacts
    ```
    
    
2.  Create and activate a virtual environment (optional but recommended):
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use: venv\Scripts\activate
    ```
3.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

**Typical Install Time:** Approximately 60 minutes on a standard desktop computer.

## 3. Sample Data and Required Downloads

We provide a small set of representative input files in `sample_data_for_demo/` to illustrate the data formats and directory structure used by the software.

### Instructions for Running a Small Test Case

1. Locate the `sample_data_for_demo/` directory in the repository. This folder contains representative ResStock, SMART-DS, and weather files used by the analysis.

2. The complete distribution network and time-series load dataset, even for the smallest case, is too large to be hosted on GitHub and must be downloaded separately. The files in `sample_data_for_demo/` are representative examples only and are **not a complete demo dataset**. In particular, the included `load_data/` directory contains only a small subset of the ResStock Parquet load files required by the provided distribution network. The sample data therefore do not contain enough input data to run the analysis pipeline end-to-end.

   The complete SMART-DS distribution network and time-series load data must be downloaded separately from the Open Energy Data Initiative (OEDI):

   https://data.openei.org/submissions/2981

   The complete SMART-DS data should retain the expected directory structure, including the network files and the full set of ResStock Parquet files under `load_data/`, for example:

   ```text
   SMART-DS/v1.0/<year>/<city>/<region>/load_data/
   SMART-DS/v1.0/<year>/<city>/<region>/scenarios/base_timeseries/
   ```

   The Thermodynamic Global Warming (TGW) Simulation Datasets used to represent historical and future weather conditions are available at:

   https://doi.org/10.57931/1885756

3. For a small test case, we recommend using the GSO/rural network, which is the smallest distribution network used in the analysis. The corresponding SMART-DS data should be located at:

   ```text
   SMART-DS/v1.0/2018/GSO/rural/
   ```

4. Update the `main_folder` path variables and configuration files to point to the local directories where the repository and downloaded datasets are stored.

5. Open the notebooks to be tested. Some notebooks depend on outputs generated by earlier notebooks and should therefore be executed in numerical order.

6. Run all cells in each notebook to generate the corresponding intermediate and final outputs.

### Expected Output

* Running the notebooks in numerical order generates time-series building demand predictions, weather-dependent SMART-DS/OpenDSS files incorporating the transformer and power-line thermal models, and power-flow outputs including current, voltage, and power.

* Notebook `4. POWER FLOW multiple snapshot PF - derating and MLP demand growth.ipynb` runs the OpenDSS power-flow simulations and generates bus-voltage, circuit-load, transformer, and power-line outputs.

**Expected Run Time:** Approximately **60–120 minutes** for the small GSO/rural test case on a standard desktop, depending on the selected weather years, timesteps, and hardware.

## 4. Instructions for Use

To run the full analysis on user-provided data, follow the modular workflow below. The analysis consists of two modules that must be executed sequentially. Within each module, notebooks must be run in numerical order, as later steps depend on outputs generated earlier.

Within Module 2, Notebooks 1–6 generate and post-process the power-flow results and should be run in numerical order. Notebooks 7.1–7.4 use the processed outputs from Notebook 6 to reproduce different manuscript results and can be run independently.

### Configuration
All user inputs (file paths, scenario parameters, and runtime options) are specified in YAML configuration files located in the `config/` directory of each module.

Before running any notebooks, update these configuration files to point to your local datasets.

Helper functions used by the notebooks are provided in the `src/` directory of each module.

### Module 1: Machine Learning Demand Forecasting

Folder: `machine_learning_demand_forecasting/`

This module handles data preparation, machine-learning-based (MLP) demand forecasting, and spatial disaggregation of predictions from feeder-level to building-level demand.

Run the following notebooks in order:

1. `DATA PROCESSING Prepare input data for training (resstock load and weather).ipynb`
   Preprocesses ResStock and weather data for model training.

2. `DATA PROCESSING Prepare input data for prediction- TGW weather.ipynb`
   Prepares climate-scenario (TGW) inputs for downstream prediction.

3. `DATA PROCESSING Create resstock dataframes.ipynb`
   Constructs structured ResStock datasets at the selected aggregation level.

4. `DATA PROCESSING Create cooling heating and non-CH data for dissaggregation process.ipynb`
   Prepares cooling, heating, and non-cooling/heating building-load inputs used for later disaggregation.

5. `TRAIN electricity demand prediction model.ipynb`
   Trains the machine learning electricity demand forecasting model.

6. `PREDICT electricity demand with climate data.ipynb`
   Generates electricity demand predictions under different climate scenarios.

7. `POST DATA PROCESSING Disaggregate feeder to buildings.ipynb`
   Disaggregates feeder-level demand predictions to individual buildings.

### Module 2: Thermal Models and Power Flow
Folder: `thermal_models_and_power_flow/`

This module constructs weather-dependent thermal inputs, runs power flow simulations on distribution networks using OpenDSS, summarizes resulting asset loading across timesteps and weather years, and generates the loading, overloading, spatial, and grid-reinforcement cost results.

Run Notebooks 1–6 in order:

1. `DATA PROCESSING convert measured building demand data to kw and pf.ipynb`
   Processes measured building demand data and creates the reduced building-demand inputs used by the thermal and power-flow workflow.

2. `DATA PROCESSING process weather and demand data.ipynb`
   Aggregates predicted demand and combines it with weather data for the selected climate scenarios and weather years.

3. `DATA PROCESSING create weather-dependent smartds files.ipynb`
   Generates weather-adjusted distribution network inputs at each selected timestep.

4. `POWER FLOW multiple snapshot PF - derating and MLP demand growth.ipynb`
   Runs power flow simulations using weather-dependent asset ratings and electricity demand.

5. `DATA POST-PROCESSING Summarize pf results across timesteps.ipynb`
   Calculates annual summary statistics for transformer and power-line loading from timestep-level power-flow outputs.

6. `DATA POST-PROCESSING Summarize pf summary stats across years.ipynb`
   Aggregates annual transformer and power-line loading statistics across the historical and future weather-year periods.

Notebooks 7.1–7.4 use the processed outputs from Notebook 6 and can be run independently:

7.1. `RESULTS Loading difference.ipynb`
Generates distributions and scatter plots of climate-driven changes in transformer and power-line loading.

7.2. `RESULTS Share of overloaded assets.ipynb`
Calculates and visualizes historical and future shares of assets exceeding at-risk and critical loading thresholds and the share of assets that transition to higher-risk loading regimes.

7.3. `RESULTS Maps at-risk assets across voltage levels.ipynb`
Maps assets experiencing climate-driven risk escalation and summarizes affected assets and capacity across voltage levels.

7.4. `RESULTS Costs.ipynb`
Calculates reactive and proactive grid-reinforcement costs and generates the corresponding manuscript figure and summary tables.
